# ⏱️ DoliSIRH : Extension Navigateur pour Dolibarr (Pointage & RH)

**DoliSIRH Extension** permet de pointer vos heures de présence, d'absence et vos temps sur les projets **Dolibarr ERP/CRM** directement depuis votre navigateur.

---

## ✨ Fonctionnalités Clés

* 🕒 **Pointage Présence / Absence (Mode RH) :** Suivi hebdomadaire avec planning attendu, calcul automatique du temps restant et historique journalier par tâche.
* 📁 **Pointage Projet Standard :** Enregistrement rapide du temps passé sur n'importe quel projet et tâche Dolibarr.
* 🔐 **Sécurité & Multi-profils :** Connexion sécurisée via l'API REST de Dolibarr avec support multi-instances et multi-entités.

---

## 🛠 Installation

1. Clonez ou téléchargez ce dépôt.
2. Ouvrez `chrome://extensions/` dans votre navigateur Chromium (Chrome, Edge, Brave).
3. Activez le **Mode développeur**.
4. Cliquez sur **Charger l'extension non empaquetée** et sélectionnez le dossier du dépôt.
